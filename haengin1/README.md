# 행인1의 메인이벤트 (EXTRA: MAIN EVENT)

> 단역으로 시작해, 메인이벤트로 끝낸다.

혜화동 성곽 아래, 출석부에서 이름이 건너뛰어지는 소년 **반시우**와 모두가 이름을 아는 유도 에이스 **강태오**가
알바로 돈을 벌고, 체육관에서 실력을 쌓고, 길거리 싸움과 야차로 이름을 얻어 아마추어 → 중소단체 → 국내 메이저 → 세계 무대의 메인이벤트까지 오르는 3D 오픈월드 액션 어드벤처. 「용과 같이」의 문법을 혜화동·고등학생·MMA로 옮긴다(커리어 사다리의 단체는 모두 가상).
