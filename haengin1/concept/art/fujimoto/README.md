## 3D로 옮길 때 주의

- **비율은 그림이 아니라 바이블 2-2 수치를 따른다.** 그림은 머리털 포함으로 재면 시우 약 7.0~7.2·태오 약 7.2~7.5등신이지만, 바이블 정의(두개골 정수리~턱끝)로 재면 시우 약 7.6~8등신으로 머리가 약간 작다. GPT Image가 다리를 길게 그리는 경향이 있어 안내선으로 눌러 둔 결과다. 그림은 얼굴·머리 모양·옷·선·색의 기준으로 쓴다.
- 시우 운동화는 바이블대로 **하이탑**(그림에서는 대부분 낮게 그려짐).
- 태오 만두귀는 `taeo_face_v1.png`가 기준(턴어라운드에는 안 보임). 태오 몸은 바이블의 통짜 그래플러 체형(복근 선·역삼각 과장 금지)이 우선.
- 시우 머리카락은 그림보다 **무거운 덩어리**로(바이블 4-1·4-2). 그림의 가는 가닥은 실루엣 참고만.
- 흑백 시트의 해칭·스크린톤은 A′(흑백 모드) 참고용. A(인게임 컬러)는 컬러 그림 두 장과 바이블 6장 색표를 따른다.

## 생성 방법

PowerShell에서 셸을 거치지 않고 호출했다(프롬프트 쪼개짐 사고 방지).

```powershell
$cli = Join-Path (npm root -g) '@higgsfield/cli/bin/higgsfield.js'
& node $cli generate create gpt_image_2_5 --prompt $p --quality high --resolution 2k --aspect_ratio 3:2 [--image-references <파일> ...] --wait --json
# 결과 JSON의 result_url(원본 png)을 내려받아 저장
```
