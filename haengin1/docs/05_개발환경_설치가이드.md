# 개발 환경 · 설치 가이드

> 확인 기준일: 2026-10-04. 가격·버전은 바뀔 수 있으니 설치 전에 공식 페이지를 한 번 더 보세요.

## 1. 엔진: Unity vs Unreal

**결론: 이 프로젝트는 Unity 6.3 LTS를 권장합니다.**

| 기준 | Unity 6.3 LTS | Unreal Engine 5 |
|---|---|---|
| 그래픽 상한 | 높음 (URP/HDRP) | **최고** (Lumen, Nanite) |
| 캐주얼·툰 스타일 | **강함** (툰 셰이더·VRoid 연동 생태계가 큼) | 가능하지만 기본이 실사 지향 |
| 캐릭터 파이프라인 | **VRoid → UniVRM → Unity**, Mixamo 휴머노이드 리타깃이 쉬움 | Mixamo 가능, VRoid는 우회 필요 |
| Claude와 협업 | **C# 코드가 전부 텍스트**, 공식 Unity CLI MCP로 에디터를 직접 조작 | 블루프린트가 바이너리라 AI가 읽고 고치기 어려움 |
| PC 사양 | 중간 | 높음 (RTX급 GPU, 32GB RAM 권장) |
| 1인·소규모 개발 | **유리** (자료·에셋스토어·한국어 강의 가장 많음) | 팀 단위에서 강함 |
| 모바일 확장 | **유리** | 무거움 |
| 비용 | Personal 무료 (매출+투자 연 20만 달러 이하). 콘솔 출시는 Pro 필요 | 무료, 게임당 매출 100만 달러 초과분에 5% 로열티 |

- 「용과 같이」는 세가 자체 엔진(드래곤 엔진)이라, 레퍼런스 때문에 Unreal을 고를 이유는 없습니다.
- **Unreal이 나은 경우**: 시안 C(반실사)를 넘어 실사급 그래픽이 목표이고, 3D 아티스트가 있는 팀이며, PC/콘솔 전용으로 갈 때.
- 둘 다 나중에 바꾸기 어렵습니다. 스토리·맵 데이터·기획서는 엔진과 무관하게 이 레포에 쌓아 둡니다.

## 4. Claude와 작업하는 방식

1. PC에 위 필수 프로그램 설치 → 이 레포를 클론. Windows는 `tools/install_windows.ps1`이 winget으로 한 번에 설치합니다(`-DryRun` 미리보기, `-Optional` 추천 도구 포함, `-SkipUnity` 엔진 확정 전).
   - 2026-10-05 대표 PC에 설치 완료: Unity 6000.3.25f1 + Windows Build Support(IL2CPP) + Visual Studio + 한국어, Unity Hub 3.22.2, VRoid Studio, GitHub Desktop (Git·Git LFS·Blender는 원래 있음).
   - 주의: Unity Hub 3.22부터 winget이 MSIX로 설치해 `C:\Program Files\WindowsApps\UnityTechnologies.UnityHub_*\app\Unity Hub.exe`에 있다. 헤드리스 `install`은 바로 반환하고 뒤에서 내려받으므로, 설치 중에 Hub를 또 부르면(예: `editors --installed`) 대기 중인 모듈 기록이 지워질 수 있다. Git LFS는 Git for Windows에 들어 있다.
2. 레포 폴더에서 Claude Code 실행.
3. Unity CLI 설치 후 `unity pipeline install` → `unity mcp configure claude` 로 연결 (공식 문서: docs.unity.com 의 *Unity CLI as the replacement for the in-Editor MCP server*).
4. 이후 "그레이박스 맵 만들어줘", "락온 전투 붙여줘" 같은 요청을 Claude가 에디터에서 직접 실행하고 콘솔 에러까지 확인합니다.

지금 클라우드 세션에서는 Unity를 실행할 수 없어서, 시안·프로토타입은 브라우저(three.js)로 만들어 링크로 보여드립니다. 기획서·스토리·맵 데이터는 그대로 Unity 프로젝트에 씁니다.
