## 2. 동선·카메라

- **진입**: `daehakro_north` 1층 문(씬 전환) → 계단 꼭대기에서 스폰 → 내려오며 방이 한눈에(스타일 프레임 g01). 신발장 앞 트리거에서 신발 벗기(시우 맨발 메시 변형, 0.4초 페이드 없이 바로).
- **허브 동선**: 계단 바닥 → (음수대·웨이트) / (매트·거울) / (케이지·샌드백) / (사무실 문). 모든 드릴 자리는 바닥의 **먹 원 마커**(`M_Decal_Atlas` 재사용)로 표시, 가까이 가면 드릴 이름 + 최고 등급 뱃지가 뜸.
- **카메라(실내 규칙, 천장 3.2 m)**: 야외 3인칭(09 문서) 기본값에서 **거리 3.0 m · 높이 1.55 m · 피치 6°**(야외 3.5/1.8/12°)로 낮춤, 세로 FOV 45 → **50**. Cinemachine Deoccluder: `Env` 레이어 벽·기둥·락커·사무실 허리벽에 막힘(최소 거리 0.8, 복귀 0.4초). **막지 않는 것**(레이어 `EnvNoCam`): 천장·보·덕트·형광등·케이지 철망·케이지 기둥·유리·샌드백·매단 물건. 천장은 카메라 피치 상한 +25°에서 클립 — 보가 화면에 걸리면 near 0.15 m 로 잘라 안쪽을 보여 줌(천장 뒷면 컬링 끔).
- **케이지 안**: 카메라 거리 2.6, 철망은 투명도 0.35 로(안에서 밖을 볼 때만), 밖에서 안을 볼 때는 불투명 컷아웃 그대로.
- **드릴 카메라(고정 프리셋, Cinemachine 가상 카메라 교체)**: 줄넘기·섀도 = 거울 정면 3/4(거울 속 시우가 보임), 미트 = 측면 3/4(코치 미트와 주먹이 한 화면), 샌드백 = 뒤 어깨 2.2 m, 스프롤·더미·그라운드 = 측면 낮은 각(높이 0.9), 스파링 = 케이지 밖 문 높이(이윤준 시점 느낌) ↔ 안쪽 M2 전투 카메라 전환, 웨이트 = 정면 3/4. 드릴 중 플레이어 카메라 조작은 끔(좌우 ±15° 만).
- **사무실**: 문 트리거로 들어가면 카메라 거리 2.2, 유리 통해 밖이 보이게 유리 레이어 `EnvNoCam`.

**이윤준 행동 규칙(설정 반영)**: 스파링·클린치 드릴의 **상대는 항상 고준 또는 관원**, 이윤준은 케이지 문·매트 가장자리에 서서 **짧은 큐**만 던진다. 미트 드릴만 직접 잡는다(머리에 충격이 오지 않는 역할). 시우 머리 피격이 중 이상이면 즉시 "스톱." → 그 라운드 종료(4-2 D11). 자기와 같은 체급·체형·성격의 시우를 '자기가 못 간 끝'까지 보내려는 시선은 대사에 은근히(칭찬 드묾, 수치로 말함: "0.3초 늦어." "각 15도 더 닫아.").

#### D01 줄넘기 기본
- **플레이**: 거울 앞. 화면 아래 박자 띠(BPM 120 → 2R 부터 132). 박자에 × 를 누르면 점프, 발이 줄에 걸리면 '걸림'(0.8초 정지·이윤준 "다시."). 박자 오차는 ±ms 로 잼.
- **지표**: 박자 오차 표준편차 ms **120 → 25**(0.40) · 걸림 수 **8 → 0**(0.30) · 후반 30초 박자 유지율 % **60 → 97**(0.30)
- **큐**: 시작 ㉾ "발끝. 뒤꿈치 닿으면 처음부터." / 라운드 ㉾ "호흡 코로." / 결과 S ㉾ "…됐네." · ㉶ "야 너 줄넘기 왜 이렇게 잘해, 어릴 때 했어?"

#### D02 줄넘기 더블언더
- **플레이**: 박자 띠에 **△ 표시 박자**가 섞임(처음 4박마다 1개 → 2박마다 1개). △ 박자에 △ 누르면 더블언더, 늦으면 걸림.
- **지표**: 더블언더 성공률 % **30 → 95**(0.40) · 최대 연속 성공 **5 → 50**(0.30) · 걸림 수 **6 → 0**(0.30)
- **큐**: ㉾ "손목만. 팔 돌리면 두 번 못 돌아." / S ㉾ "손목 됐어. 다음은 발목."

#### D03 섀도복싱 콤비 호출
- **플레이**: 거울 앞. 코치가 콤비를 **번호 음성 + 아이콘 띠**로 호출("원-투-쓰리-슬립": 1 잽 □, 2 크로스 △, 3 왼 훅 □ 길게, 4 오른 어퍼 △ 길게, 5 왼 바디 L↓+□, 6 오른 바디 L↓+△, K 킥 R2, N 니 R2 길게, S 슬립 ×, R 롤 L↓+×). 호출 후 0.4초 안에 첫 입력, 콤비 끝나면 **가드 복귀**(R1 톡). 틀리면 아이콘이 먹으로 지워짐. 1R 3타 콤비, 2R 4타+슬립, 3R 5타+롤·킥.
- **지표**: 콤비 정확도 % **50 → 98**(0.35) · 첫 반응 ms **900 → 350**(0.25) · 가드 복귀율 % **50 → 95**(0.25) · 콤비 내 타격 간격 안정(표준편차 ms) **160 → 50**(0.15)
- **큐**: ㉾ "원투. 원투쓰리. …슬립 늦어, 0.3초." / ㉾ "가드. 치고 손 내려오면 맞아." / S ㉾ "거울 보지 마. 상대를 봐." · ㉶ "형, 쟤 지금 나보다 빠른 거 아니에요?"
- **M2 재사용**: 입력 → `MoveDef` 발생·판정 프레임 그대로 재생(잽 191·크로스 192·훅 193·어퍼 194·킥 207·니 211, 슬립 156·롤 158), `InputClock` 버퍼 12f, 연결 창 규칙(08 문서 3-2) 그대로 — 즉 **콤비 정확도는 M2 콤보 판정 함수**로 센다.

#### D04 미트 치기
- **플레이**: 이윤준이 매트 가장자리에서 미트를 듦. 콤비 호출(D03 과 같은 코드) → 미트가 **들리는 순간**(코치 애니 이벤트)이 기대 타격 시각. 입력 → M2 공격 발생 프레임 → **판정 프레임이 미트 부채꼴과 겹치면 '팡!'**(히트스톱 0.06, 의성어 작은 '팡'), 오차 = |판정 시작 − 미트 들림|. 3R 는 코치가 미트로 **반격 스윙**(머리 위로) → 슬립·롤 타이밍.
- **지표**: 타이밍 오차 평균 ms **180 → 45**(0.35) · 콤비 정확도 % **55 → 98**(0.30) · 반응 ms **800 → 320**(0.15) · 후반 유지율(3R 평균 오차 / 1R 평균 오차 역수, %) **60 → 95**(0.20)
- **큐**: ㉾ "원. 투. …늦어. 미트 보지 말고 내 어깨 봐." / ㉾ "각 15도 더 닫아. 그래야 어깨가 가려." / S ㉾ "…그래. 그게 네 원투야." · 밤 개인 지도(스토리) 때는 큐가 길어짐(대사 바이블 담당).
- **M2 재사용**: `resolveHit` 부채꼴 판정을 **미트 콜라이더**에 그대로(사거리 0.9·반각 40°), `TimeFx` 히트스톱 약(0.06), 피격 젖힘 대신 **미트 젖힘**(코치 상체 IK 6°), 의성어 폰트·먹 이펙트 작은 판.

#### D05 샌드백 라운드
- **플레이**: 백 앞. 자유 타격이지만 **박자 띠**(BPM 100)가 있고, 박자 안에 치면 '리듬 타격'. 파워 = 입력 홀드 길이(△ 길게 = 강)와 리듬 보너스 합. 백이 흔들리면 **돌아올 때**(백 애니 이벤트) 치면 파워 ×1.3. 치고 1.0초 안에 R1 가드 복귀 안 하면 백이 어깨를 '툭'(가드 복귀율 깎임). 3R 마지막 20초는 **'막판 몰아치기'** 호출.
- **지표**: 타격 리듬 오차 ms **200 → 60**(0.30) · 파워 유지율(3R 마지막 30초 평균 파워 / 1R 첫 30초, %) **50 → 92**(0.30) · 가드 복귀율 % **50 → 95**(0.20) · 라운드당 타격 수 **60 → 150**(0.20)
- **큐**: ㉾ "백 따라가지 마. 오는 걸 쳐." / ㉶ "막판! 막판! 20초! 다 쏟아!" / S ㉾ "힘 빼고 쳤는데 그 소리가 나네."
- **M2 재사용**: 타격 판정·히트스톱(약/중)·의성어·먹 튐. 백은 `Rigidbody` 흔들림(힌지 2단) + 체인 소리.

#### D06 스피드백
- **플레이**: 좌-좌-우-우 리듬(BPM 150→170→190). 박자에 □/△ 교대, 틀리면 백이 튕겨 0.6초 멈춤.
- **지표**: 최대 연속 타격 **10 → 200**(0.40) · 박자 오차 ms **90 → 20**(0.40) · 실수 수 **10 → 0**(0.20)
- **큐**: ㉾ "눈 감고도 되게." / ㉶ "이거 나 300 간다, 봐봐— 아 씨."

#### D07 스프롤 드릴
- **플레이**: 매트. 코치(고준)가 랜덤 간격(1.2~3.0 s)으로 **'샷!'** 하며 낮게 들어오는 모션(애니 이벤트) → 플레이어 **L↓ + ×**(스프롤: 엉덩이 뒤로, 가슴 압박). 반응 창 0.7 s. 스프롤 뒤 **R1**(가슴 눌러 컨트롤) 0.3 s 안에 누르면 '자세 OK'. 페이크('샷' 없이 어깨만 들썩)에 반응하면 실수.
- **지표**: 반응 ms **700 → 280**(0.40) · 자세 성공률 % **50 → 97**(0.35) · 복귀 시간 ms(스프롤→스탠스) **1200 → 600**(0.25)
- **큐**: ㉾ "엉덩이. 손 말고 엉덩이가 먼저." / ㉶ "샷! 샷! …페이크지롱." / S ㉾ "테이크다운 하나는 막겠네."

#### D08 더미 테이크다운
- **플레이**: 더미(`grappling_dummy`) 앞. 3단 입력 타이밍 바: ① **레벨 체인지 ○**(바 녹색 구간 60 ms 폭) → ② **페네트레이션 스텝 L↑**(0.25 s 안) → ③ **드라이브 △ 홀드**(게이지 채움, 0.5 s) → 피니시(더블: 들어올려 넘김 / 싱글: 다리 들고 돌림, 자동). 더블 1R 10회, 싱글 1R 10회.
- **지표**: 레벨 체인지 타이밍 오차 ms **250 → 60**(0.35) · 단계 순서 정확 % **50 → 98**(0.35) · 피니시 성공률 % **40 → 95**(0.30)

### 4-3. 등급 산식 (결정론, 테스트 가능)

```
지표 i: 값 v_i, D 기준 d_i, S 기준 s_i, 가중치 w_i (Σ w_i = 1)
  higher-is-better:  m_i = clamp01( (v_i − d_i) / (s_i − d_i) )
  lower-is-better:   m_i = clamp01( (d_i − v_i) / (d_i − s_i) )
점수 score = round( 100 × Σ w_i · m_i , 1 )
등급 = S  if score ≥ 90 and min(m_i) ≥ 0.75
     = A  if score ≥ 75
     = B  if score ≥ 60
     = C  if score ≥ 45
     = D  otherwise
```
- 반올림·clamp 외 난수 없음. 같은 `DrillLog` → 같은 결과(테스트 G01).
- **스탯 보정은 지표 값이 아니라 입력 창에만**: 스피드가 높으면 타이밍 '허용 창'이 넓어져(기본 ±60 ms → 스피드 100 에서 ±110 ms) 플레이어가 같은 손놀림으로 더 낮은 오차를 기록한다. 산식 자체는 스탯과 무관(현실성: 등급 = 실제로 한 것).
- 표시: 결과 카드에 점수는 숨기고 **등급 큰 글자 + 지표 막대 4개**(막대 = m_i), 막대 아래 작은 글자로 실제 값("오차 72 ms").

### 4-4. 등급별 배율표

| 등급 | 땀 배율 | 주 스탯 | 부 스탯 | 관계도(코치) | 그 외 |
|---|---|---|---|---|---|
| D | ×0.4 | +0 | +0 | 0 | ㉾ "…" (무언) |
| C | ×0.7 | +1 | +0 | 0 | |
| B | ×1.0 | +2 | +1 | 0 | |
| A | ×1.35 | +3 | +1 | +1 | |
| S | ×1.8 | +4 | +2 | +2 | **첫 S**: 땀 +50 · 시뮬 해금 연출 · 도감 뱃지 |
| 시뮬(해금 후) | S 의 **75%**(×1.35) | +3 | +1 | 0 | 몽타주 15 s, 이벤트 없음 |

피로 비용은 등급과 무관하게 표대로. 피로 70 이상이면 땀·스탯에 ×0.6.

### 4-5. S 등급 → 시뮬레이션

**권장 해석 = '자동 진행'**: 어떤 드릴에서 S 를 **한 번** 찍으면 그 드릴은 다음부터 '시뮬'로 돌릴 수 있다.

| 규칙 | 값 | 이유 |
|---|---|---|
| 해금 | 드릴별, S 1회 | "S 를 찍으면 시뮬레이션 돌릴 수 있게" |
| 실행 | 훈련 선택 화면에서 드릴 옆 **[시뮬]** 토글 → 15초 몽타주(3컷: 준비·중반·마무리, 땀 카운터 올라감) → 결과 카드('시뮬' 표시, 등급 없음) | 시간 절약이 목적 |
| 게임 시간·피로 | **100% 그대로**(슬롯 1개 소비, 피로 표대로) | 공짜 훈련이 아님. 몸은 똑같이 쓴다 |
| 보상 | S 보상의 **75%**(땀 ×1.35, 주 +3·부 +1), 관계도 0, 이벤트 0 | '직접 하면 100%' 유인 |
| 하루 상한 | 시뮬 **2회/일**(한 슬롯 1회) | 하루 전체를 자동으로 보내지 못하게 |
| 피로 상한 | 피로 **60 이상이면 시뮬 불가**(직접은 85까지) | 피곤할 땐 코치가 봐야 한다는 현실성 |
| 검정 | 시뮬 **8회마다** 다음 1회는 직접 해야 하고 **B 이상**이어야 시뮬 유지. 미만이면 시뮬 잠김 → 다시 S | 실력은 유지해야 한다. '등급 유지 검정' |
| 예외 | 스토리 지정 드릴(첫 스파링·밤 개인 지도)·D11 스파링은 **시뮬 불가**(머리 안전 = 코치가 봐야 함) | 설정·안전 |
| 루틴(2부) | 2부(배달·학교·훈련 지옥 스케줄)부터 **'루틴'**: 시뮬 가능한 드릴 최대 3개를 한 슬롯에 묶어 실행. 보상 각 **50%**, 피로 합의 80%, 하루 1루틴 | 바쁜 일정에서도 스탯을 '유지'하는 장치. 새 S 는 직접만 |
| 저장 | `DrillSave{ bestGrade, sCount, simUnlocked, simRunsSinceCert, lastGrade }` 드릴별 | |

**다른 해석(대표 확인용) = '가상 대전 시뮬'**: S 를 찍은 드릴들의 데이터(내 타이밍·반응·파워 곡선)로 **가상 스파링 시뮬레이터**를 돌려 대회 상대(스카우팅 데이터)와의 예상 흐름을 보여 주는 장치 — 대회 전날 사무실 노트북에서 실행, 결과는 '라운드별 우세 예측 + 약점 1줄'. 이 경우 시뮬은 훈련 대체가 아니라 **정보**다. 구현 비용은 비슷(전투 AI 를 화면 없이 돌리고 요약), 설계는 4-6 의 `DrillSimRunner` 자리에 `FightSimRunner` 가 들어간다. → 결정 10-3.

### 12-1. 설계와 다르게 한 것
1. **D05 라운드당 타격 기준 60→150 을 20→50 으로 환산** — 표는 현실 3분 기준, 게임 라운드는 60초(4-1). 다른 지표는 표 그대로.

### 12-2. 남은 문제
- 밤 시간대가 어둡다(Zone1 밤 필름 볼륨의 파란 스플릿 톤이 실내에 그대로) — 체육관 전용 볼륨 또는 밤 형광등 세기 조정 필요.
- 동작: 줄넘기·스프롤·새우·브릿지·케틀벨·타이어 전용 클립 없음 → Stance+코드 점프(줄 LineRenderer)·Dodge·Kneel·Lie·Tackle 로 대신(4-8 동작 주문 12종 미생성, 8cr/개 = 약 96cr, 대표 승인 뒤).
- D09 클린치·D12 서킷·D13 타이어·D14 로드워크(야외 기록 올리기)는 자리만. 루틴(2부)은 산식·시험만.
- 드릴 중 카메라 ±15° 조작, 사무실 문 카메라, 신발 벗기(맨발 메시), 음악·오디오 클립 없음(자리만).
- 성능: 실내 2.2~2.4M 삼각형(캐릭터 비중) — 캐릭터 LOD(Tripo 메시 감축)로 0.55M 목표.
- NPC 동작 반복은 상태 전이 코드(GymNpc.Routine)라 단조로움, 관원 얼굴은 적 모델 그대로.
- 시우 체육관 복장(회색 티·맨발·헤드기어 메시)은 캐릭터 파이프라인 담당 — 지금은 교복 + 머리 캡.
