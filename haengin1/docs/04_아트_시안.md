# 3D 아트 시안 (1차)

시안 페이지: `concept/style_drafts_3d.html` — 같은 장면(혜화동 성곽길, 10월 은행나무, 배달 자전거, 치즈냥이)을 세 가지 그림체로 렌더링하고, 기술 버튼으로 타격 연출을 비교한다.
페이지의 3D 인형은 코드로 즉석에서 만든 임시 모델이다. 고르는 대상은 **비율·명암·외곽선·색감·이펙트 방향**이다.

| | A 애니 셀셰이딩 | B SD 치비 | C 스타일라이즈드 |
|---|---|---|---|
| 비율 | 6.3~6.8등신 | 2.75~3등신 | 6.9~7.3등신, 손발 과장 |
| 명암 | 2단 툰 | 3단 소프트 툰 | PBR + 골든아워 |
| 외곽선 | 굵은 남색 | 색을 따라가는 굵은 선 | 없음 |
| 타격 이펙트 | 만화 임팩트 + 의성어(퍽! 빡!) | 별·하트 팝 + 동글한 의성어 | 땀·먼지 파티클, 의성어 없음, 히트스톱 1.2배 |
| 레퍼런스 | 하이파이 러시, 젠레스 존 제로 | 파티 애니멀즈, 폴 가이즈 | 시푸, 포트나이트, 용과 같이 조명 |
| 제작 | VRoid → Blender → Unity(lilToon) | Blender 직접 모델링 | Blender 모델링·텍스처 + Mixamo/Cascadeur |
| 1인 개발 속도 | 가장 빠름 | 빠름 | 느림 |

## 공통 캐릭터 디자인 (17세)

- **반시우**: 162cm. 살짝 그을린 피부, 부스스한 곱슬머리, 콧등 반창고, 한 치수 큰 남색 교복 재킷을 열어 입음(소매 걷음), 느슨한 넥타이, 테이프 감은 주먹, 흰 운동화(주황 밑창). 표정은 늘 조금 화나 있음.
- **강태오**: 183cm. 넓은 어깨, 투블럭, 왼쪽 만두귀, 흰 셔츠 소매를 걷고 재킷은 허리에 묶음, 단정한 넥타이, 남색 운동화(파랑 밑창). 잘 웃고, 엄지 척.
- 교복: 남색 재킷 + 학교 배지, 흰 셔츠, 빨강 바탕에 금색 사선 줄무늬 넥타이, 회색 바지.
- 코너 컬러: 시우 = 레드 코너(선셋 오렌지), 태오 = 블루 코너(딥 블루).

## 선택 후 진행

1. 고른 시안 기준으로 캐릭터 정식 모델 제작 (A라면 VRoid로 바로 시작 가능)
2. 혜화동 그레이박스(성대 후문~와룡공원)에 같은 조명·후처리 적용
3. 전투 프로토타입에 시안별 이펙트 세트 이식
