## 1. QA 봇(`-qa`) — 빌드에서 사람처럼 하기

`Scripts/Dev/QaBot.cs`(감시·도우미) · `QaBot.Play.cs`(A 구역 = 새 게임부터 데모 끝까지) · `QaBot.Lab.cs`(B 구역 = 중간 저장에서 하나씩 골라 시험). 빌드에만 들어가고 `-qa` 가 없으면 아무것도 안 함.

```
HaenginMainEvent.exe -qa -mute -nocursorlock -qaout <폴더> [-qapart ab] [-qaonly A1,B07,...] [-qabase lab_base.json] [-qalap 0] -logFile <로그>
```

- 가상 키보드(Input System `QueueStateEvent`) + 창 초점 무시 + Windows 전원 절약 끄기(`SetProcessInformation` — 안 끄면 숨은 창이 7fps 로 떨어짐). 시간은 `Time.captureDeltaTime` 1/60(녹화·A8 은 1/30)로 고정.
- 남기는 것: `shots/NNN_구역_이름.jpg`(+`shots.tsv`) · `rec/<이름>/f_*.jpg`(30fps 녹화) · `lap/f_*.jpg`(12프레임마다 한 장) · `qa_log.txt` · `findings.tsv`(자동 발견) · `log_counts.tsv`(경고 종류별 수).

## 6. 함정(다음 사람에게)

- **편집기·시험 사진으로는 블룸·HDR 문제가 안 보인다** — `Shots.Grab` 은 LDR RT. 빌드 화면을 `ScreenCapture.CaptureScreenshotAsTexture` 로 찍어 봐야 함(QA 봇 B00).

- URP 기본 볼륨 프로필(`PC_RPAsset` 의 Default Volume Profile)은 장면 볼륨이 없을 때도 늘 섞인다 — 새 효과는 장면 볼륨에서 켤 것.
