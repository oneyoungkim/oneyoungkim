## 1. 범위

### 1-1. 기획서의 M3 를 어떻게 읽었나

- 기획서 9장 M3 = "시우 루트 1~5화 + 배달 미니게임 + 첫 반항 보스전 + 정식 모델 2명". 첫 반항 보스전은 6·7화(튜토리얼 보스전 1·2페이즈)라, 데모는 결국 **1막 「출석부」 7화 전체**가 된다.
- 원고 1~7화 본문이 약 4만 1천 자다(1~4화만 약 2만 4천 자). 그대로 옮기면 1시간 반이 넘는다. 그래서 **회차마다 핵심 장면 2~6개만 남기고**, 나머지는 몽타주·카드·대사 몇 줄로 줄이거나 뺀다(1-3).
- 데모가 보여 줘야 할 것: ① 「용과 같이」식 동네(혜화동 새벽·밤) ② 배달·알바로 굴러가는 생활 ③ '참는 아이'가 쌓이다가 터지는 이야기 ④ M2 전투 손맛 ⑤ 후지모토풍 인물. 이 다섯 가지가 한 번씩은 크게 나오게 장면을 골랐다.

### 1-6. 대사 원칙

1. **원고 문장을 고쳐 쓰지 않고 고른다.** 대사(따옴표)와 속마음(1인칭 내레이션) 중에서 장면당 3~8줄만 고른다. 속마음은 시우 1인칭의 맛이라 전체 줄의 40% 안쪽으로 남긴다.
2. **태오 루트와 맞춘 지정 대사는 글자 그대로**(회차 구성 부록 A): 1화 출석부("반시우? …반시우 없니?" / "쌤, 뒤에요. 뒷문에 있어요." / "아 행인1이네ㅋㅋ"), 4화 우유팩(민재 "행인1은 우유 먹어서 뭐 하냐? 어차피 뼈로만 갈 건데." → … → "그럼 뭔데. 불쌍해서?"). 시각(8:10)·순서(지퍼 = 임찬, 손바닥 = 건우, 우유팩 = 민재, 태오 일곱 걸음)도 그대로.
3. **17세 규칙**: 흡연·음주 0. 국밥집 테이블에 술병 없음(물병·깍두기·수저통), 편의점에 주류 칸·담배 진열장 없음(그 자리엔 상비약·핫바 선반), 현장 형들 담배 없음. 소품은 흰 우유·초코우유·바나나우유·이온 음료.
4. **이름**: 가게·학교는 가상(혜성고, 하루편의점, 성대후문 국밥, 번개배달, 빵집 = '로터리제과'(가칭), 물류 트럭 = '하루물류'(가칭), 인력사무소 = '새벽별 인력사무소'(가칭)). 실존 랜드마크는 실명(성대 후문, 와룡공원, 한양도성 성곽, 혜화동 로터리, 대학로). 캠퍼스 대학 이름은 계속 쓰지 않는다(06 15장 결정 2 대기).
5. **라디오·TV 소리**: 최사장 트로트 라디오는 실제 곡을 쓰지 않는다 — 합성한 '웅얼거리는 라디오' 소리.

### 6-3. 헤드리스·무음 녹화

- **방식**(M2 와 같음): 에디터 배치 PlayMode(`-batchmode`, **`-nographics` 빼기** — 창은 안 뜨고 GPU 로 그림), `Time.captureDeltaTime = 1/60`, 3프레임마다 1920×1080 PNG → `ffmpeg -framerate 20 … -an -c:v libx264 -pix_fmt yuv420p`로 **소리 트랙 없는 mp4** + 12칸 띠 사진. 녹화 테스트는 인자를 줄 때만 돈다: `-d08shots <폴더>`(주행) · `-d10shots`(노가다) · `-d11shots`(편의점) · `-d12shots`(땋기) · `-d14shots`(보스전) · `-d16shots`(회차별) · `-d17shots`(데모 전체). 테스트 이름은 `ZStoryShots`·`ZMiniShots` 처럼 Z 로 시작(입력 테스트 뒤에 돌게).
- **소리**: 배치 모드에선 `AudioListener.volume = 0`, 재생 횟수만 센다(08 11-3). 녹화 mp4 에는 소리 트랙을 넣지 않는다. 확인은 mp4·PNG 로만 하고, **게임이나 녹화를 앱 안 브라우저에 띄우지 않는다**.
- **봇**: `StoryBot` — 장면 목표를 사람 손과 같은 길(`InputScript`)로 한다: 대사 넘기기(설정한 읽기 속도), 선택지는 정해 둔 답, 주행은 길 가운데선 따라가기 + 리듬, 미니게임은 판정 창 가운데, 전투는 M2 `FightBot`.
- **빌드 스모크**: `C:\클로드\haengin1-builds\M3\HaenginMainEvent.exe -batchmode -nographics -m3smoke -logFile …` — 창·소리 없이 데모 봇이 끝까지 가고 스스로 종료. 안 끝나면 **그 PID 만** 끈다(이름으로 끄지 않음). 실제 창·소리·패드는 대표 PC 에서 직접 한 판.
- **배치 실행 주의**(unity/README 5장): `$env:TMPDIR = $env:TEMP`, Unity Hub 켜 두기, 같은 프로젝트를 에디터와 배치가 동시에 열지 않기, `-runTests` 에 `-quit` 붙이지 않기.
