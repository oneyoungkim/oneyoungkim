### 2-3. 소품 후처리 (`tools/env_assets/normalize_prop.py`)

1. 메시 하나로 합치기, 겹친 정점 합치기
2. 생성기별 기본 회전(Tripo −90°, Hunyuan·SAM 0°) + 소품별 보정(`specs/props_final.json` 의 yaw — 자전거 +90°, 가로등 −90°)
3. 면 수 제한(Decimate, `props_meta.json` 의 face_limit — 5천~2만)
4. 실측 크기: 기본은 높이로 맞춤, 소품에 따라 너비·길이·세 축 각각(트럭은 생성 비율이 뚱뚱해 세 축)
5. 바닥 z = 0, 가로세로 중심 0, 평면 법선(셀 그림자가 면 단위로 또렷)
6. 재질: 금속성 0·거칠기 1, 텍스처 영웅 2048 / 반복 1024
7. **팔레트 맞춤**: 텍스처의 쓰인 화소를 참조 그림의 물체 화소에 Lab 평균·표준편차로 맞춤(강도 .85). Hunyuan 이 L* 를 10~15 낮게, 채도를 높게 굽는 것을 되돌린다(쓰레기통 L* 26 → 40, 참조 40)
8. GLB 내보내기(+Y 위, +Z 정면 — glTF 규약). 결과 수치 `props/props_report.json`

## 13. 남은 문제와 대표 결정

**남은 문제**
1. 소품은 생성 메시라 모서리가 키트보다 덜 또렷하다 — 평면 법선 + 팔레트 맞춤으로 줄였지만 Unity 셀 렌더에서 한 번 더 봐야 한다(P1). 지저분한 것은 같은 참조 그림으로 다시 뽑기(11cr).
2. 가는 부분이 있는 소품(빨래 건조대 살, 롤테이너 철망, 전봇대 애자)은 면 수 제한에서 뭉개질 수 있다 — 화면에서 문제면 그 부분만 코드 메시로.
3. 생성 텍스처에 빛이 약간 구워져 있다(Hunyuan). 셀 그림자와 겹치면 이중 그림자 — UTS '그림자 1단' 경계를 위로 올려 상쇄하거나 해당 소품만 텍스처 밝기 평탄화.
4. 목표 그림은 2D 일러스트라 세밀한 해칭이 많다 — 3D 에선 재질 결 + 화면 공간 외곽선으로 '느낌'만 맞춘다. 비교 기준은 색·밀도·실루엣.
5. `parking_barrier` 팔 길이 2.5m — 주차장 입구 폭에 맞춰 X 만 늘릴 것.
6. 혜화문 문루·성곽 여장은 아직 키트(건물 생성기) 몫 — 그 결과를 보고 P4 에서 문루만 생성 시험할지 정한다.

**대표 결정 필요**
1. **소품 생성기 = Hunyuan3D v3 표준으로** — 권장: 그대로(Tripo 보다 2cr 비싸지만 셀 렌더 품질 차이가 큼). 단순한 상자형 반복 소품만 SAM 3D(1cr) 허용.
2. **하루편의점 색 = 슬레이트 파랑 + 크림 띠 + 노란 해**(그림 f01·f08 의 청록·흰 띠 대신) — 권장: 이대로. 실존 편의점과 덜 닮게 하려면 B 안 '탁한 청록 + 크림'도 가능(띠 1장 다시 뽑기 2.75cr).
3. **혜화문 문루**: 이미지 → 3D 1회 시험(약 14cr) / 키트로 직접 / 외주 — 권장: 키트 결과를 먼저 보고, 모자라면 이미지 → 3D 시험. 데모에선 원경·카드라 급하지 않음.
4. **2차 소품(P4)** 실내 무대용 약 15개(약 180~220cr) — 권장: P1(Unity 적용) 결과를 본 뒤 승인. 이번 상한(900)의 남은 188.5 로는 15개가 빠듯함.
5. 유료 에셋 스토어 팩 — 권장: 사지 않음(화풍 불일치, 2-2).
