## 2. 「용과 같이」에서 가져오는 것

용과 같이의 문법을 그대로 빌리되, 야쿠자 대신 **고등학생·알바생·격투기 선수**의 현실로 바꾼다.

| 용과 같이 | 행인1의 메인이벤트 | 비고 |
|---|---|---|
| 카무로초 (가부키초를 압축) | **혜화동** (실제 지리를 수평 1/4로 압축) | 걸어서 5~7분이면 끝에서 끝. 밀도가 핵심 |
| 길에서 양아치가 시비 → 그 자리가 전장 | **인카운터**: 골목·계단·편의점 앞에서 시비 → 주변 행인이 원을 만들고 바로 전투 | 로딩 없이 전환, 끝나면 다시 거리 |
| 히트 게이지 / 히트 액션 | **기세 게이지 / 기세 액션** | 맞히고, 버티고, 도발에 안 넘어가면 차오름 |
| 환경 히트 액션 (자전거·간판·가드레일) | **동네 기세 액션**: 성곽 계단, 배달 자전거, 편의점 파라솔, 공사장 안전콘, 은행나무 | 장소마다 고유 연출 |
| 보스 등장 시 이름 카드 | **이름 카드**: "혜화동 성곽 호랑이 — 채강혁" | 시안 페이지에 시연 구현됨 |
| 전투 스타일 전환 (용과 같이 0) | **스타일**: 시우 = 깡(길거리) → 복싱 → MMA / 태오 = 유도 → MMA | 스토리 진행으로 해금 |
| 서브스토리 | **동네 사연** (서브스토리) — 성곽 벤치 할아버지, 길고양이 밥 주는 대학생, 소극장 지망생 등 | 웃기고 짧게, 가끔 울림 |
| 미니게임 (가라오케·UFO캐처·마작) | **알바 + 놀이**: 배달, 노가다, 편의점, 연극 단역 / 코인노래방, 인형뽑기, PC방 격투게임, 성곽 러닝 | 알바는 돈+스탯, 놀이는 관계+멘탈 |
| 경험치로 능력 해금 | **땀** 포인트로 스탯·기술 해금 (훈련·알바·전투에서 획득) | |
| 진지한 본편 ↔ 엉뚱한 서브 | 동일 | 진지함과 개그의 낙차가 이 장르의 맛 |

**가져오지 않는 것**: 조직 폭력 미화, 무기 위주 전투, 과한 유혈. 이 게임의 싸움은 결국 링(케이지)으로 가는 이야기다.

## 3. 코어 루프

```
하루 = 새벽 · 아침(학교) · 오후 · 저녁 · 밤
 └ 시간대마다 할 일 1~2개 선택 → 체력·피로·돈·스탯 변화 → 밤에 집에서 저장/회복
     ├ 학교: 수업(멘탈) · 점심 이벤트 · 쉬는 시간 시비
     ├ 알바: 배달 · 노가다 · 편의점 · 연극 단역 → 돈 + 부가 스탯
     ├ 훈련: 체육관 · 성곽 러닝 · 줄넘기/미트 → 핵심 스탯
     ├ 거리: 인카운터 · 야차 · 동네 사연
     └ 대회 날: 아마 → 프로(케이지 서울) → 로드 투 UFC → UFC
```

- **피로**가 높으면 훈련 효율·전투력이 떨어지고 부상 확률이 오른다. 쉬는 것도 전략.
- **돈**은 식비(편의점 단백질·바나나우유·국밥), 체육관 회비, 동생 학원비, 장비에 쓴다. 시우 루트는 돈이 빠듯하고 태오 루트는 넉넉한 대신 '기대'라는 압박 게이지가 있다.
- **관계도**: 가족, 친구, 코치, 라이벌. 높으면 대회 날 응원 버프, 이벤트 해금.

### 스탯

| 스탯 | 오르는 곳 | 전투 영향 |
|---|---|---|
| 파워 | 노가다, 샌드백 | 타격 대미지 |
| 스피드 | 미트, 배달(타임어택) | 공격 속도, 회피 |
| 스태미나 | 성곽 러닝, 줄넘기 | 기세 게이지 유지, 라운드 후반 |
| 맷집 | 스파링, 노가다 | 받는 대미지 감소, 다운 저항 |
| 기술 (타격/레슬링/주짓수) | 체육관 수업, 유도관 | 기술 해금, 잡기·그라운드 |
| 멘탈 | 학교, 가족, 연극 알바 | 도발 저항, 위기 시 기세 회복 |

## 4. 전투

### 4-1. 조작 (패드 기준)

| 입력 | 동작 |
|---|---|
| □ 약공격 연타 | 잽·원투 콤보 (최대 4타) |
| △ 강공격 | 콤보 마무리 / 단독 강타 |
| ○ 잡기 | 멱살·클린치 → 던지기 / 무릎 / 테이크다운 |
| × 회피 | 스텝·더킹 (타이밍 맞추면 '읽었다' 판정 → 기세 +) |
| R1 가드 | 막기 (오래 막으면 가드 크러시) |
| L1 락온 | 상대 고정 / 다수전 대상 전환 |
| △ (기세 MAX) | 기세 액션 — 상황·장소·상대 상태에 따라 다른 연출 |

어렵지 않게: 버튼 연타만으로도 이길 수 있고, 회피·잡기 타이밍을 알면 더 시원하게 이긴다.

### 4-2. 타격감 규칙 (시안 데모에서 검증 중인 수치)

| 요소 | 약타 | 중타 | 강타/기세 |
|---|---|---|---|
| 히트스톱 | 0.06초 | 0.095초 | 0.16~0.2초 |
| 화면 흔들림(트라우마) | 0.28 | 0.45 | 0.8~1.0 |
| 피격자 번쩍임 | 0.1초 | 0.1초 | 0.1초 |
| 넉백 | 5cm | 10cm | 16cm + 다운 |
| 슬로모션 | — | — | 0.5~0.75초, 30% 속도 |
| 의성어 | 퍽! | 빡! | 콰직! 쿵! |

- 피격자는 히트스톱 동안 미세하게 떨린다 (격투게임의 '히트 셰이크').
- 카메라는 강타 때 살짝 당겨진다 (줌 펀치). 기세 액션은 카메라가 상대를 중심으로 붙는다.
- 사운드는 저음 '쿵' + 고음 '탁' 2겹. 체급이 클수록 저음 비중을 키운다.
- `prefers-reduced-motion` 사용자는 흔들림 30%, 플래시 끔 (접근성 옵션).

### 4-3. 싸움의 세 무대

| 무대 | 규칙 | 보상 |
|---|---|---|
| **인카운터 (길거리)** | 다대일 가능. 주변 사물 사용. 경찰 사이렌이 들리기 전에 끝내기 | 돈 약간, 땀, 동네 평판(±) |
| **야차** | 합의된 1:1. 무기 금지, '항복' 판정 있음. 구경꾼 원 = 링 | 판돈, 평판 크게, 라이벌 관계 |
| **MMA** | 케이지·라운드(아마 3×3분, 프로 3×5분, 타이틀 5×5분)·심판·판정 | 전적, 랭킹, 상금, 스토리 진행 |

### 4-4. MMA 모드 추가 규칙

- **클린치/테이크다운**: 잡기 → 방향 입력 미니게임(유도 잡기 싸움처럼 깃 싸움)
- **그라운드**: 간이화. 탑 포지션이면 파운딩/서브미션 시도(연타·타이밍), 바텀이면 일어나기/스윕(타이밍)
- **라운드 사이 1분 = 코너 타임**: 코너맨(표관장·채강혁)의 조언 2~3개 중 하나 선택 → 다음 라운드 버프. *코너맨 세계관 공유 포인트*
- **판정**: 유효타·테이크다운·컨트롤 시간을 화면 구석에 '심판 메모'로 은근히 보여준다

## 6. 동네 사연 (서브스토리) 샘플

1. **반촌 씨름 할아버지** — 성곽 벤치에서 "옛날 반촌 사람들은…" 전설을 들려주는 할아버지. 3번 찾아가면 숨겨진 기세 액션 '반촌 업어치기' 해금.
2. **치즈냥이 실종 사건** — 와룡공원 길고양이를 찾아 성곽 안팎을 뒤진다. 찾으면 고양이가 집 옥상에 놀러 옴.
3. **소극장 지망생의 오디션** — 대사 한 줄을 끝까지 못 하는 배우를 위해 시우가 연습 상대(대사 없는 행인 역)를 해 준다.
4. **배달 별점 테러범** — 매번 별 1개 주는 손님의 정체는 외로운 독거 할머니. 이후 단골.
5. **노가다 현장의 형틀목수 장갑** — 아버지 이름이 적힌 오래된 장갑. 곽반장의 회상.
6. **편의점 도둑 고딩** — 잡고 보니 중학생 시절의 시우 같은 아이. 혼내지 않고 삼각김밥을 사 준다.
7. **대현TV 촬영** — 오대현 유튜브 콘텐츠로 성곽 계단 1,000개 챌린지. 조회수 = 평판.
8. **혜화유도관 40주년** — 태오 루트. 동네 사람들이 다 모이는 잔치. 시우가 국밥 배달로 등장.
9. **새벽 러너의 인사** — 매일 새벽 마주치는 둘. 277일째에 드디어 인사(태오 루트 장치와 연결).
10. **엄마의 고향 음식** — 응운 파가 친(Chin) 음식을 국밥집 메뉴로 내놓기까지. 손님 모으기 미니 퀘스트.
