# 16. 인터페이스 B안 「중계 화면」

2026-11-05 대표가 인터페이스 시안 A·B·C 가운데 B안 「중계 화면」을 골랐다. 게임의 모든 화면 UI 는 이 문서의 규칙을 따른다. 새 화면도 같다.
시안 원본: 세션 scratchpad `ui_sian/B_1.jpg`(동네)·`B_2.jpg`(드릴)·`B_3.jpg`(드릴 결과)·`B_4.jpg`(대화·선택지), 수치 `sian.py` B 블록(1600 기준). 아래 수치는 1920×1080 기준(시안 × 1.2).
코드: 공용 부품 `Scripts/UI/UiKit.B.cs` · 움직임 `Scripts/UI/UiMotion.cs` · 글꼴 `Scripts/UI/UiFonts.cs` · 글자 감사 `Scripts/Dev/TextAudit.cs`.

## 1. 규칙

1. 판: 먹 #1A1417, 화면에서 보이는 불투명도 0.93(`UiKit.InkPlate`), 곧은 모서리. 기울임·거친 테두리·그림자 없음.
2. 강조 줄 5px(`UiKit.Plate(..., Edge.Top / Edge.Left)`): 상태 판·큰 판은 위쪽 주황 #E2582C, 알림 판은 왼쪽 주황, 문자 알림·속마음은 왼쪽 Warm. 드릴 안내·조작 안내·상호작용 판에는 줄이 없다.
3. 이름띠: 주황 바탕 먹 글자(Noto Sans KR Black) — 말하는 사람·코치(`UiKit.NameTag` · `SetTag`). 문자 알림은 이름띠가 아니라 머리말 '문자 · 엄마'.
4. 작은 머리말: PaperDim #CCC7BD Noto Medium 18px(`UiKit.Label`). 판 안 구분선은 미리 섞은 불투명 색 (75,71,72) 1px(`UiKit.Rule`).
5. 숫자(시각·돈·횟수·등급·타이머·라운드)는 Barlow Condensed Bold(`UiFonts.N`). 바뀌는 숫자는 자리 폭 고정(`UiKit.Tab` = 숫자 덩어리만 `<mspace=0.45em>`, 서식 태그 안 숫자는 건너뜀 — 타이머만 0.5em). 본문 글꼴 글 속 숫자를 Barlow 로 할 때는 `UiKit.NumRich`(버프 칩 값·결과 덧말).
   - 예외(2026-11-05 결정): 대사·선택지 **문장 속** 숫자('15:00까지')는 본문 글꼴 그대로. HUD 제목류('다음' 판 시각 등)만 Barlow.
   - 조작 안내 줄(조작 보기·드릴 안내·휴대폰 발·일시정지 발·계획표 발·패배 안내·전투·자전거·대사 안내)은 키 이름을 빠짐없이 Warm(종이 바탕은 AccentText)으로 칠한다. 안내 글을 만들 때 키에 `[키]` 표시를 붙이고(자료), `UiKit.KeyMark` 가 표시만 감싼다 — 낱말 짐작(정규식)에 기대지 않음(3단계 결정 ②). 계획표 발은 지금 입력 장치의 키(키보드 Enter·Space, 패드 ×).
   - 키 기호 □△○× 는 속 빈 모양 그대로 한 단계 크고(118%) 굵게 그린다(■▲ 채움 대신). 키 칩의 '×' 는 Barlow 대체로 높이가 절반이라 본문 Bold 115% 로 그려 A·Enter 와 높이를 맞춘다.
   - 결정 ③: 자료 줄의 숫자는 Barlow(`UiKit.NumRich`) — 이야기 날짜 판 시각, 휴대폰 문자 시각, 휴대폰 가계부 탭·가계부 표의 돈. 문자 본문 같은 문장 속 숫자는 본문 글꼴.
   - 안내 줄의 ' · ' 앞은 줄 안 바꿈 빈칸(`UiKit.Glue`) — '·' 가 줄 첫머리에 오지 않음. 한글은 띄어쓰기에서 줄이 갈림(TMP 현대 한글 규칙).
6. 한글: Noto Sans KR Medium(본문 `UiFonts.M`) · Bold(버튼·안 고른 줄 `UiFonts.B`) · Black(제목·이름 `UiFonts.K`).
7. Black Han Sans(`UiFonts.Br`)는 의성어에만(드릴 '팡!' 판은 의성어 목록 `DrillHud.IsWord` — '페이크!·순서!' 는 Noto Black). 예외: 타이틀 로고 「행인1의 메인이벤트」(그림 제목).
   Gaegu(`UiFonts.H`)는 세계 안 손글씨에만: 봉투·하늘 코팅 메모(`LedgerUi`)·체육관 화이트보드(`DrillMenu` 보드)·서명·출석부. 스토리보드 카드 대사는 손글씨가 아니라 본문.
8. 주황은 큰 글자·띠·선택 막대에만(먹 판 위 약 4.3~4.9:1). 작은 강조 글자는 Warm #D9955A(약 6.4~7.3:1). 종이 판 위 작은 주황 글은 `AccentText`.
9. 선택 목록: 고른 줄 = 종이 판 + 왼쪽 주황 6px + 먹 글자(Black) · 안 고른 줄 = 먹 판 + 종이색 글자(Bold)(`UiKit.ListRow` · `SetRow`). 일시정지·드릴 메뉴·고르기·무대 대화 선택·계획표 단추가 이 규칙. 못 고르는 줄은 PaperDim 글자.
   - 종이 바탕 변형(타이틀, 3단계 결정 ①): 고른 줄 = 먹 판 + 왼쪽 주황 6px + 종이 Black · 안 고른 줄 = 판 없음 + 먹 Bold(`UiKit.SetRowOnPaper`) — 고른 줄이 가장 진하게.
10. 키 표시: 종이색 2px 테두리 상자에 Barlow(`UiKit.KeyChip`, 정수 px — 1.5 는 변마다 1·2px 로 그려졌음). 상호작용 키(E·×)만 주황 칸에 먹 글자.
11. 글자 감사 규칙 유지: 판(화면 기준 실효 불투명도) ≥ 0.85 · 대비 4.5:1(큰 글자 3:1) · 글자끼리 안 겹침 · 화면 밖 없음 · 월드 글자는 표면에만(`TextAudit`, 시험 Q57, QA 봇 `text_bad.tsv`).
12. **반투명 지정(선형 색공간, 2026-11-05)**: 프로젝트가 Linear 색공간이라 UI 알파는 선형 빛 공간에서 섞인다. 알파 값을 그대로 쓰면 시안(브라우저 sRGB 섞기)보다 훨씬 옅게 보인다(0.93 판이 밝은 배경에서 0.73~0.84).
    - 어두운 반투명(먹 판·덮개)은 `UiKit.Seen(색, 시안 알파)`로만 지정한다. 흰 배경에서 시안과 같게 보이는 섞기 알파로 바꿔 준다(8비트 올림). 먹 판 0.93 → 0.992, 덮개 = 시안 먹 #0E0B0C × 0.86 → 0.98(흰 배경이 약 46). 어두운 배경에서는 시안보다 조금 진하다.
    - 판 위에 놓이는 밝은 반투명(트랙·구분선·보상 선·박자 지난 눈금·버프 칩 색 띠)은 반투명으로 두지 않는다. 미리 섞은 불투명 색: 트랙 `UiKit.Track` (56,51,50 — 3단계에서 63,58,57 을 조금 어둡게) · 구분선 `UiKit.RuleColor` (75,71,72). 색 띠 위 글자는 `UiKit.TagBand`(먹 Black 우선, 4.5:1).
    - 막대 채움 대 트랙 밝기 대비 ≥ 3:1: 주황 3.35:1 · 알바 판정 칸 초록 (96,170,104) 4.4:1. 위험 붉은색은 Endure(#7A1E1E)가 트랙과 1.1:1 이라 밝힌 `UiKit.EndureLit` #FF4040(3.6:1)을 쓴다. 트랙 위 Warm 글 4.97:1.
    - 글자 감사는 글자마다 실제 색(`<color>`·키 Warm)과 `<mark>` 배경으로 재고, 글자끼리 겹침·판 끝 걸침·가림은 잉크(글자 모양) 상자로 잰다(줄 상자의 글꼴 위·아래 여백은 셈하지 않음).
    - 글자 감사(`TextAudit.Over`)도 선형으로 섞어 화면과 같은 값을 잰다. 판 값 = 흰·검은 배경 위 합성으로 잰 sRGB 실효 불투명도.

## 3. 정보 구조

- '다음' 안내: HUD 한 줄과 위 가운데 길잡이 띠가 겹치던 것 → 오른쪽 위 판 하나(머리말 `다음 · 장소 · 73m`). 자유 이동 중엔 세계 HUD 가, 이야기 이동 장면에선 길잡이(RouteHud — `RouteSetup` 이 같은 판을 만듦)가 그림. 자유 이동 중 길잡이 '도착'·완주 알림 동안 머리말이 '도착'.
- 조작 안내 줄: 기본 접음 — 왼쪽 아래 「조작 보기」 칩, 키 H(패드 R3). 펼치는 때 = 첫날(새 게임 튜토리얼 흐름) · 이번 실행에서 처음 보는 안내(8초) · 사용자가 켬. 펼친 줄 끝에 'H 접기'.
  - 설정 '조작 안내 자동/펼침/접음'(타이틀 설정, `haengin.hint.open` −1·1·0). '접음'이면 처음 보는 안내도 안 펼침.
  - 대사 판이 떠 있으면 칩은 숨기고 펼친 안내는 대사·속마음 판의 실제 위 끝 위로.
  - 칩·펼친 안내를 숨기는 화면: 드릴 결과 카드 · 휴대폰 · 계획표 · 고르기 · 장 카드 · 드릴 메뉴 · 무대 대화·패배(`GameState.Modal`) · 스토리보드 · 회차 카드 · 알바 · 땋기 · 먹 닦기. 칩이 안 보이면 H · R3 토글도 막힘.
- 선택지 `[ ]` 괄호는 화면에서만 뺌(데이터·`ChoiceUi.Label` 그대로).
- 드릴 결과: 등급을 가장 크게, S 만 주황. 표 막대 = D→S 지표 점수(횟수·ms 는 값 비율로 정할 수 없음) — 막대 오른쪽 끝 S 눈금 + 머리말 'S 기준까지'. 값 서식은 그대로('0점인데 40%' = D −2·S 3 이라 맞는 값).
- 피로 막대: 85 이상 위험 붉은색(`EndureLit`) · 그 밖 주황.
- 한글 단위는 숫자에 붙임(0회·0점), 'ms' 앞 빈칸·% 는 그대로.

## 5. 움직임(`UiMotion`, 2026-11-05)

- 판 등장: `UiKit.Plate` 로 만든 판(상태 판·'다음' 판·길잡이 판·알림 판·대사·속마음·휴대폰·도감·가계부 표·계획표·일시정지 등)과 날짜 판은 붙은 쪽(앵커)에서 10px · 150ms ease-out 으로 미끄러져 들어옴. 투명도는 그대로(등장 중에도 판이 비치지 않음). 다른 코드가 그 사이 자리를 옮기면(쌓이는 알림 등) 미끄러짐을 멈춤. 목록 줄(선택지·메뉴 줄)은 움직이지 않는다.
- 사라짐: `UiMotion.Hide` — 100ms 옅어진 뒤 꺼짐(코치 말·날짜 판). 사라지는 중에 다시 켤 때는 `UiMotion.Show`(취소하고 다시 보임).
- 흔들림 줄이기면 결과 카드 나타남(줄 70ms·막대·등급 크기·S 뒤집기)도 바로.
- 돈·피로 숫자: 바뀌면 250ms 동안 옛 값 → 새 값(`WorldHud` Roll).
- 타이머: 라운드 마지막 10초 주황 + 1초마다 1.04배 맥박(0.25초에 돌아옴).
- 결과 표: 한 줄씩 70ms 간격, 등급이 마지막.
- 흔들림 줄이기(`Accessibility.Reduced`)면 미끄러짐·옅어짐·맥박·숫자 올라감 없이 바로. 시간은 `UiKit.RealDt`.
