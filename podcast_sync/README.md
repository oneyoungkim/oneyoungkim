# 팟캐스트 자동 편집기 (podsync)

카메라 3대와 마이크로 찍은 팟캐스트를 자동으로 **싱크 → 마이크 소리만으로 믹스 → 색 맞춤 → 멀티캠 컷 편집**까지 해서 영상 한 편으로 만들어 줍니다.

| 단계 | 하는 일 |
|---|---|
| 싱크 | 모든 파일을 소리로 맞춥니다. 녹음기마다 다른 시계 오차(드리프트)까지 보정해서 1시간이 지나도 밀리지 않습니다. |
| 오디오 | 라이카·후지 카메라 소리는 **쓰지 않고**, DJI Mic 3 자체녹음 + 포켓(Mic Mini 2) 소리만 씁니다. 저음 잡음 제거 → 노이즈 제거 → 사람별 목소리 크기 맞춤 → 오토믹서(말하는 사람 마이크만 열어서 옆 사람 마이크로 새는 소리·방 울림 감소) → 유튜브 기준 음량(-14 LUFS) |
| 색 | 라이카 Q2를 기준으로 포켓·후지를 맞춥니다. 같은 순간의 두 카메라 화면에서 **같은 물체(얼굴·옷·벽·소품)를 수백~수천 곳 찾아** 그 색이 같아지도록 밝기·대비·화이트밸런스·채도를 계산합니다. 보정값은 LUT(.cube) 파일로도 드려서 프리미어/다빈치/캡컷에서 그대로 쓸 수 있습니다. |
| 컷 편집 | 라이카 60% · 포켓 25% · 후지 15% 비중으로, 말하는 사람이 바뀌는 순간에 맞춰 카메라를 전환합니다. |

## 사용법 (윈도우)

1. 압축을 아무 곳에나 풉니다.
2. **`run_windows.bat`** 을 더블클릭합니다.
   처음 한 번은 Python·FFmpeg·필요한 부품을 자동으로 설치합니다(인터넷 필요, 5~10분). Python 설치 뒤 창을 닫고 다시 더블클릭하라는 안내가 나오면 그대로 하면 됩니다.
3. **브라우저에 편집기 화면이 열립니다.** (안 열리면 검은 창에 나온 주소를 브라우저에 붙여넣기)
4. 화면에서 순서대로:
   - **촬영 폴더**: [폴더 선택…] 을 눌러 고르거나 경로를 붙여넣고 [파일 확인]. 최근에 쓴 폴더는 아래에 버튼으로 남습니다.
   - **파일 확인**: 파일마다 어느 장비인지 자동으로 나옵니다. 틀린 게 있으면 오른쪽 목록에서 바꾸세요.
   - **설정**: 카메라 비중, 메인 카메라, 해상도, 음량, 잡음 제거, 오토믹서, 색 맞춤.
   - **만들기**: 먼저 [테스트 만들기] (중간 1~5분만) → 결과를 화면에서 바로 재생해 보고 → 괜찮으면 [전체 편집본 만들기].
5. 다 끝나면 오른쪽 위 [프로그램 종료] 를 누르거나 검은 창을 닫습니다.

- 검은 창은 프로그램 본체입니다. 작업 중에 닫으면 작업이 멈춥니다.
- [중지] 로 멈췄다가 다시 만들면 이미 만든 영상 조각은 건너뛰고 이어서 합니다. 싱크 분석 결과도 저장돼 있어서 두 번째부터는 빠릅니다.
- 터미널 방식이 편하면 `run_windows.bat --cli` 로 실행합니다.

## 파일 분류 규칙

- 폴더 이름에 `라이카` / `후지` / `포켓` / `마이크` 가 들어 있으면 그 장비로 봅니다.
- 아니면 파일 정보(제조사)와 파일 이름으로 판단합니다. `L100….MP4` = 라이카, `DSCF….MOV` = 후지, `DJI_….MP4` = 포켓, 소리만 있는 파일(WAV 등) = DJI Mic 3
- 틀렸거나 "알 수 없음"이면 화면의 파일 목록에서 장비를 골라 주세요. 고른 내용은 `_편집결과\파일분류.csv` 에 저장돼 다음에도 쓰입니다.

## 로그(D-Log M / F-Log)로 찍었다면

제조사 공식 변환 LUT를 촬영 폴더에 `pre_pocket.cube`, `pre_fuji.cube` 이름으로 넣어 두세요. 그 LUT를 먼저 적용한 뒤 라이카 색에 맞춥니다. HLG로 찍은 영상은 자동으로 일반 영상(SDR)으로 변환합니다.

## 터미널(명령어) 옵션

화면 대신 명령어로 돌릴 때 씁니다. 명령 프롬프트에서 `run_windows.bat --cli "G:\딥마카이" --height 1080` 처럼 씁니다.

| 옵션 | 뜻 |
|---|---|
| `--weights leica=60,pocket=25,fuji=15` | 카메라 비중 |
| `--height 1080` | 1080p로 출력 (4K보다 훨씬 빠름) |
| `--lufs -16` | 최종 음량 (유튜브 -14, 팟캐스트 플랫폼 -16) |
| `--denoise 6` | 노이즈 제거 세기 dB (기본 10, 0 = 끔) |
| `--no-automix` | 오토믹서 끄기 (모든 마이크를 항상 열어 둠) |
| `--color-strength 0.5` | 색 맞춤 세기 (0~1, 기본 1) / `--no-color` 는 끄기 |
| `--encoder nvenc` | 인코더 지정 (기본은 NVIDIA → 인텔 → AMD → CPU 순으로 자동 선택) |
| `--mode test --test-minutes 5` | 테스트 길이 바꾸기 |

## 알아둘 점

- **처리 시간**: 4K 전체 편집본은 컴퓨터 성능에 따라 몇 시간이 걸릴 수 있습니다. 그래픽카드 인코더가 있으면 자동으로 써서 훨씬 빠릅니다. 급하면 해상도에서 1080p를 고르세요.
- **싱크 정확도**: 시험 촬영본(시계 오차를 일부러 넣은 가짜 촬영본)에서 마이크끼리 0.4ms 이내, 영상은 프레임 단위(원본 프레임 간격의 절반 이내)로 맞았습니다.
- **색 맞춤**: 카메라끼리 같은 물체가 보여야 정확합니다(보통 와이드 카메라에는 다 보입니다). 겹치는 물체가 적으면 화면 전체 통계 방식으로 자동 전환되고, 이때는 구도 차이 때문에 완전히 똑같아지지는 않습니다. 리포트에 어느 방식을 썼는지와 "같은 물체 색차이(ΔE)" 전후 값이 나옵니다(3 이하면 눈으로 거의 구분 안 됨). `색보정_비교.jpg` 를 보고 필요하면 프리미어에서 LUT 위에 살짝 조정하세요.
- **카메라 전환**: 누가 어느 카메라에 나오는지는 모르기 때문에 비중과 "말하는 사람이 바뀌는 순간"을 기준으로 자릅니다. 특정 장면을 바꾸고 싶으면 컷리스트를 참고해서 프리미어에서 손보면 됩니다.
- 영상 두 개의 프레임레이트가 다르면(예: 25p와 30p) 메인 카메라(라이카) 기준으로 맞추며, 이때 일부 프레임이 반복됩니다.

## 맥 / 리눅스

`python3 -m pip install -r requirements.txt` 후 `python3 -m podsync` 로 실행하면 같은 화면이 열립니다(ffmpeg 필요). 명령어로만 돌리려면 `python3 -m podsync --cli "/촬영/폴더"`.

## 개발자용 검증 도구

`tools/make_synthetic.py` 는 4명 대화, 카메라 3대, 녹음기별 시계 오차, 카메라별 색 차이를 넣은 가짜 촬영본을 만듭니다. `tools/verify_synthetic.py` 는 결과 영상의 프레임마다 새겨진 실제 시각 바코드와 소리를 읽어서 싱크·음질·색을 채점합니다(espeak-ng 필요).
